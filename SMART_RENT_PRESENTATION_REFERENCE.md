### SLIDE 2: INTRODUCTION

#### 1. Background
- Rapid migration of students and young professionals to educational and tech hubs (Bangalore, Pune, Hyderabad).
- High rental inflation forces young people to share 2BHK/3BHK flats and PG accommodations to split costs.
- Existing property portals focus only on real-estate sales, treating tenants merely as commercial buyers.

#### 2. Motivation
- Incompatible habits (sleep schedules, hygiene standards, dietary preferences) cause daily friction and mid-lease dropouts.
- Students waste heavy broker commission fees on unverified rooms with hidden maintenance charges.
- To build an intelligent single-window platform that verifies roommate habit compatibility before moving in.

#### 3. Scope
- Students can manually type any locality or college name to search verified independent PGs and shared rooms.
- 1-click Google Maps navigation provides direct external route viewing without heavy screen clutter.
- Tenants can view transparent itemized expense shares in Indian Rupees (₹) and use an automated fair rent calculator.

### SLIDE 7: RESEARCH GAPS
1. **Lack of Lifestyle Compatibility Evaluation**: Existing portals match properties purely by budget and city, completely ignoring daily living habits like sleep routines, cleanliness standards, and dietary preferences.
2. **Absence of Resident-In-Place Discovery**: Current housing applications only list vacant apartments, offering no feature to join an active flat where a compatible person is ALREADY living.
3. **No Unified System for Itemized Expenses and Fair Rent Splitting**: Advertised rental rates conceal extra utility, maid, and food charges, with no objective mathematical tool to split rent fairly based on room sizes.

### SLIDE 10: METHODOLOGY
#### System Architecture Layers:
- **Presentation Layer (Frontend)**: React 18, Tailwind CSS, Lucide Icons, Vite
  - OTP Login Form, Profile Onboarding, Manual Location Bar, Verified PG Cards, Rent Breakdown Modal, Live Compatibility Quiz.
- **Application Layer (Backend)**: Python 3.11 + FastAPI (REST API Engine)
  - Mobile Auth Verification, Cosine Compatibility Matchmaker, Manual Location Filter, Fair Rent Splitter Calculator, Property Listings API.
- **Database Layer**: SQLite / PostgreSQL with SQLAlchemy ORM
  - User Profiles, Habit Vectors, PG Listings Data, Itemized Expense Records, Contact Records.

#### Operational Progress Flow:
- **Step 1: User Onboarding** (Mobile OTP verification & profile setup)
- **Step 2: Lifestyle Survey** (User rates sleep, cleanliness & diet on a 1–5 scale)
- **Step 3: Compatibility Matching** (Calculates mutual match % using Cosine Math)
- **Step 4: Manual Area Discovery** (Type location manually & open Google Maps)
- **Step 5: Rent & Splitter** (Itemize costs in ₹ & calculate fair room rent shares)
